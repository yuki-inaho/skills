# 質問の枝（バッチ生成用チェックリスト）

各枝から「ここが曖昧だと壊れる」ものだけを拾う。答えが資料から自明な質問は出さない。

| 枝 | 問いの例 |
| :--- | :--- |
| 目的 | 成功をどう測るか / 誰の何が良くなるか / やらないことは何か |
| スコープ | どこまで今回やるか / 境界の外は何か / 将来の拡張をどう扱うか |
| データ | 入力の正本はどれか / 欠落・不正時の契約は / 再現性はどう担保するか |
| 失敗 | 失敗の定義は / 失敗時に何を残すか / ロールバック手順は |
| 運用 | 誰が回すか / 頻度は / 監視と通知は / コスト上限は |
| 成功指標 | 合格ラインの数値は / 比較対象は / いつ測るか |
| リスク | 最悪ケース / 影響範囲 / 回避不能ならどう緩和するか |
| 代替案 | 他に候補はあったか / 却下理由は / 再評価の条件は |
| 依存 | 外部チーム・API・データの約束は / 破られたらどうするか |

## バッチ出力テンプレート

```text
N 問で出します（変更可）。

【目的】
Q1（目的）: <質問>
  なぜ: <曖昧なままだと壊れること>
  推奨: <推奨回答>

【スコープ】
Q2（スコープ）: ...
```
