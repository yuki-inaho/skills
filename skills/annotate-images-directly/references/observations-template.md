# 観測記録のテンプレート

案件側へコピーして使用します。項目を埋めるために感想、原因、時刻、数値を作らないでください。未取得は `unknown` または `null`、未実施は「未実行」と記録します。共有スキルへ実画像・実得点・実パス・参照答案を転載しません。

## 試行と観測範囲

- 試行ID／対象の予定ID一覧:
- 入力・契約・手順の版とハッシュ:
- 注釈担当へ実際に渡した画像と資料:
- 参照を見た時点: 未開示／回答確定後／混入あり（確認範囲を記載）
- 実行基盤が返したモデルID・設定・終了理由と、その根拠:
- 初稿／修正版／重畳図／検査結果／凍結記録:
- 未提出・失敗・中断・未実行:

## 参照を見る前の findings / tips / struggles

| 種別 | 観測した事実 | 根拠となる成果物・箇所 | 仮説と未確定点 |
| --- | --- | --- | --- |
| findings（判明したこと） | | | |
| tips（次回に使える手順） | | | |
| struggles（困難・失敗） | | | |

tips は実際に試した操作と確認結果に結び付けます。境界が見やすくなったという観測と、公式得点が改善したという主張は分けます。

## 変更と再確認

| 変更前の問題 | 変更内容・理由 | 同じ入力での再確認 | 適用範囲 | 未検証・残る不確かさ |
| --- | --- | --- | --- | --- |
| | | | | |

初稿を残し、修正前後の原画像・重畳図と幾何結果を確認します。変更回数や警告の減少だけで意味の正しさが改善したとは書きません。別領域での確認は、使った条件と実際に完了した操作までを記載します。

## 回答確定後の評価

- 回答確定と参照開示の順序を確認できる記録:
- 正本の採点器と版、画素化・分母・集約方法:
- 幾何の合否と補助警告:
- 原画像上で確認した品質・未確認箇所:
- 公式の得点と対象範囲、欠測・除外・失敗:
- 参照を見てから分かったこと:
- 参照を見て変更した場合の別試行ID:

## 共有する手順への反映判断

- 一般化する判断・手順と、それを支える観測:
- 案件側へ残す対象固有の条件・結果:
- 今回の変更が運用指示の修正か、同一条件の比較で裏付けた改善か:
- 反映後に確かめた範囲と、まだ実証していない再利用性:
