# Blender再現可能アセット制作

## 条件を固定する

1. 利用者の目的、参照、生成に使える入力、納品物、完了条件を記録する。独立制作を求められた場合、元頂点・器官座標・材質・写真画素を設定へ転記して独立制作と呼ばない。
2. リポジトリ指示、要求仕様、最新引き継ぎ、作業書、既存生成/描画入口を読む。旧configが別モデル用でないか保存済み現物と照合する。
3. Blender版/ビルド、依存lock、入力/ソース/設定ハッシュ、種、カメラ、色管理を固定する。参照版と生成版が違う場合は区別し、元blendを古い版で保存し直さない。

## 制作して受け入れる

1. bpyはBlender内蔵Pythonで動かす。ゼロベース生成はfactory emptyから開始し、別出力先へ保存する。提供blendの自動スクリプト実行を無効にする。
2. 部品ID、親、接続、単位を先に定義する。共有メッシュと別オブジェクトを使う場合、個体IDを共有データに固定しない。
3. 局所部品→1対象→2配置→全体の順に受入する。接続、巻き方向、退化面、自己交差、浮遊、編集性を適切な粒度で検査する。接続中心線の一致と、融合面の水密性は別に記す。
4. 小さい実レンダーを画像表示で開く。通常の納品受入では全景、作業点接写、裏/側面を同じ保存版で確認する。固定カメラの局所試行では視点・解像度・samplesを変えず、その試行の観測範囲を明記する。葉だけ/空環境など必要対象が写らない画像を納品の代わりにしない。
5. 変更理由を絞って同条件比較し、失敗/採否を残す。形状欠陥をぼけ・露出・隠蔽で見えなくして合格にしない。
6. 保存blendを別プロセスで開き、依存・タグ・件数を検査する。一時コピーで代表部品を編集し、元ファイル不変とID保持を確認する。

細い器官の体積・向き検査は、メッシュを平行移動しても判定が変わらないことを確認する。ワールド原点から遠い小形状で符号が変わったら、まず代表中心へ移した座標と倍精度の安定和で再計算し、正巻き/逆巻きの解析形状を複数位置で試す。閾値を緩めたり形状を原点へ動かしたりして監査を通さない。

代表メッシュの自己交差検査だけでは、別object同士の相互侵入を保証できない。密集した独立物体は実保存メッシュのworld変換を用いて対ごとの干渉を調べる。外包球の非重なりは非交差の十分条件であり、外包球の重なりだけは実交差の証明にならない。疑わしい対は内包形状や面交差で確かめる。画像上の重なりと3D侵入を分け、個数・ID・サイズ等を保持して配置を直し、付属部品と注釈を再生成する。全体gateは株/集合をまたぐ対も含め、空間分割の候補漏れを独立確認する。

## 注釈と再現を検証する

校正画像では[測定契約](references/measurement-contract.md)を読む。大きい観測JSONは同文書の「観測結果を読む順序」に従い、設定・保存現物・画像内の可視性を対応付けてから判断する。RGBと数値正解を同じ評価済み形状/カメラ/時刻へ結び付ける。不透明検査を解除して透過材質の問題を隠さない。

同設定/種を二つの空出力先で生成し、正規化した形状/変換/ID/材質/カメラ指紋を比較する。blendの保存時刻等を含むバイト一致と幾何再現性を分ける。同一環境の再描画はRGB/数値画像のハッシュを比較し、検証範囲だけ主張する。

## 保存して報告する

最新モデル・監査・レンダーの版対応をmanifestへ残す。指定保存先/公開範囲を守り、コード・重いアセット・私有参照を区別する。依頼された節目でcommit/push/notesを確認し、ローカルとリモートを混同しない。

実モデル、実画像、検証、使い方を渡す。環境準備や単体試験だけで造形完成としない。参照画像・レンダー・画面撮影を正しく区別する。
